# Нэвтрэх дэлгэцийн дэвсгэр зураг

Энд `background.jpg` нэртэй файл тавина.

Зураг байхгүй ч нэвтрэх дэлгэц бүрэн ажиллана — доор нь давхарлагдсан
градиент харагдана. Тиймээс зураг солих нь ганц файл солих ажил, код
хөндөхгүй.

Зөвлөмж:

- Өргөн (1920×1080-аас дээш), 500KB орчим JPEG.
- Бичвэр нь ЗҮҮН талд сууж, хагас тунгалаг хөшгөөр таслагддаг тул
  сонирхолтой хэсэг нь БАРУУН талд байх нь тохиромжтой.
- Харанхуй, гэрэл хоёр горимд ижил зураг хэрэглэгдэнэ.
