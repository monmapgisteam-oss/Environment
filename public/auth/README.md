# Нэвтрэх дэлгэцийн дэвсгэр зураг

Одоогийн файл: **`background.webp`** (1831×859, 170KB).

Эх хувилбар нь 2.1MB PNG байсныг WebP болгож 8% болгож шахсан. Зураг
солих бол мөн ижил замаар: эхийг нь `sharp`-аар WebP болгож
(`quality: 82`) энэ нэрээр хадгална. Код хөндөхгүй.

Зураг байхгүй ч нэвтрэх дэлгэц бүрэн ажиллана — доор нь давхарлагдсан
градиент харагдана.

## ⚠ Зургийн БҮТЭЦ нь байрлуулалтыг тодорхойлно

Одоогийн зураг нь нийслэлийн зураглал, зангилаануудыг **ЗҮҮН** талдаа
агуулж, баруун тал нь бүдгэрсэн уулархаг дэвсгэр. Тиймээс нэвтрэх
бичвэр **БАРУУН** талд сууж, хөшиг нь тэр тийш өтгөрдөг.

Шинэ зураг тавихдаа гол агуулга нь аль талд байгааг хараарай:

- агуулга ЗҮҮН талд → бичвэр баруунд (одоогийн тохиргоо)
- агуулга БАРУУН талд → `sign-in.tsx` дотор `justify-end`-ийг хасаж,
  хөшгийн `bg-gradient-to-l`-ийг `-to-r` болгоно

Хоёуланг нь зэрэг эргүүлэхгүй бол хөшиг нь яг гол агуулгыг дарна.

## Бусад зөвлөмж

- Өргөн (1600px-ээс дээш), 2:1 орчим харьцаа.
- Харанхуй, гэрэл хоёр горимд ижил зураг хэрэглэгдэнэ.
- Нарийн дэлгэцэнд зураг голоороо хайчигддаг тул гол агуулга нь
  хэт захад байвал утсан дээр алга болно.
