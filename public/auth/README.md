# Нэвтрэх дэлгэцийн зураг

| Файл | Хэмжээ | Үүрэг |
|---|---|---|
| `envi-7.webp` | 1832×859 · 96KB | Гол зураг болон хажуугийн дэвсгэр (`sign-in.tsx`) |

## ⚠ WebP, PNG БИШ

Эх `envi_7.png` зураг нь 1.64MB PNG байсныг **96KB** болгосон — 17 дахин хөнгөн.
Энэ бол хэрэглэгч бүрийн нээх ЭХНИЙ дэлгэц тул жин нь шууд мэдрэгдэнэ.

Зураг солих:

```bash
node -e "
require('sharp')('<эх зураг>')
  .webp({ quality: 88 })
  .toFile('public/auth/envi-7.webp')
  .then(() => console.log('ok'));
"
```

⚠ `sign-in.tsx` дээр зургийн хэмжээ (`width` / `height`) бичигдсэн байдаг
тул өөр хэмжээтэй зураг тавихад түүнийг ДАГУУЛЖ засна — эс тэгвээс
хөтөч буруу байрлал тооцоолж, ачаалагдах үед зураг үсэрнэ.

## Байрлуулалт

Байрлуулалтыг `sign-in.module.css` удирдана. Зургийн бүтэц (агуулга нь
аль талдаа байгаа) өөрчлөгдвөл бичвэрийн тал ба хөшгийн чиглэл
ХОЁУЛАА дагаж эргэх ёстой — ганцыг нь өөрчилвөл хөшиг гол агуулгыг
дарна.
