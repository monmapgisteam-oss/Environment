# Нэвтрэх дэлгэцийн дэвсгэр зураг

Одоогийн файл: **`background.webp`** — 3060×1940, 350KB.

Хүрээний зай нь `scripts/make-auth-background.mjs`-ийн гурван тогтмолоор
тохируулагдана: `BLUR` (150), `SATURATION` (0.25), `VEIL` (0.88).

⚠ **Хүрээний өнгө платформын суурьтай (`--paper`, #0f1720) тааруулагдсан.**
Ханал, хөшиг ХОЁУЛАА хэрэгтэй: зөвхөн хөшиг өтгөрүүлбэл зургийн
ногоовтор-цэнхэр өнгөний өнцөг үлдэж хүрээ нь платформын хүйтэн
слэйтээс ялгарсаар байна, зөвхөн ханал бууруулбал гэрэлтэлт нь өндөр
хэвээр.

| ханалт · хөшиг | Дөрвөн ирмэгийн дээд зөрүү |
|---|---|
| 1.00 · 0.55 | 43 (баруун, дээд тод ялгарна) |
| 0.50 · 0.72 | 24 |
| 0.35 · 0.82 | 15 |
| **0.25 · 0.88** | **9** |

Зургийн баруун дээд тал (нар жаргах тэнгэр, хотын гэрэл) гэрэлтэй тул
тэр хоёр ирмэг хамгийн их зөрдөг — тааруулалтыг тэднээр хэмжинэ.

⚠ **Хэмжихдээ `stats()` ХЭРЭГЛЭХГҮЙ.** Тэр нь `extract`, `composite`
зэрэг дамжуулгын үйлдлийг тооцдоггүй тул үргэлж ЭХ зургийн тоог буцаана
(дөрвөн ирмэг яг ижил гарвал энэ алдаа мөн). `.extract().removeAlpha()
.raw().toBuffer()` хэрэглэж, сувгийн тоог шалгана.

⚠ **ХҮРЭЭ НЬ ФАЙЛ ДОТРОО ШАТААГДСАН.** Зотон 3060×1940, дотор нь
2560×1440 зураглал дөрвөн талаасаа **250px** зайтай сууна. Зай нь ижил
зургийн бүдгэрүүлсэн хуулбар.

## Зураг солих

```bash
node scripts/make-auth-background.mjs <эх зураг>
```

Скрипт нь зотоныг угсарч `public/auth/background.webp` бичнэ. Эх зураг
нь **хүрээгүй, цэвэр зураглал** байна — скрипт зайг нь өөрөө нэмнэ.

⚠ Эх файл нь SVG байвал эхлээд доторх зургийг гаргаж авна: ирсэн
хувилбарууд нь вектор биш, нэг `<image>` доторх base64 PNG байсан
бөгөөд SVG нь эх PNG-ээсээ ~33% том.

## Яагаад хүрээг файл дотор хийдэг вэ

CSS дээр `inset`-ээр хүрээ гаргаж туршсан. Хоёр асуудалтай байв:

1. **Хүрээний зузаан цонхны хэмжээнээс хамаарч хэлбэлздэг** — том
   дэлгэц дээр нимгэн, жижиг дээр бүдүүн харагдана.
2. **`bg-cover` нь зураглалыг ӨӨРИЙГ нь хайчилдаг** — цонхны хэлбэрээс
   шалтгаалж дээр доороос 8–27% хүртэл хасагддаг байв.

Файл дотор хийхэд хүрээ нь дэлгэц бүрд ижил ХАРЬЦААТАЙ болж, хайчлалт
эхлээд хүрээний зайг иддэг тул зураглал хамгаалагдана.

⚠ Мөн `bg-contain` туршаад буцаасан: тэр нь зургийг бүтнээр багтаадаг ч
хоёр талд хоосон зурвас үлдээдэг бөгөөд зүүнийхийг нь бичвэрийн хөшиг
дардаг тул зураг **зөвхөн баруун талдаа илүү зайтай** мэт харагддаг байв.

## ⚠ 250px нь санамсаргүй биш

Хөтчийн цонхны харьцаа 1.76–2.08-ын хооронд хэлбэлздэг. Зайг түүнээс
нимгэн авбал зураглалын ирмэг хасагдаж эхэлнэ:

| Зай | Зөөврийн | Бүтэн HD | QHD | MacBook |
|---|---|---|---|---|
| 150px | хасна | хасна | бүтэн | бүтэн |
| 200px | хасна | бүтэн | бүтэн | бүтэн |
| **250px** | **бүтэн** | **бүтэн** | **бүтэн** | **бүтэн** |

Хэт өргөн (ultrawide 3440×1337) болон босоо таблет дээр хүрээ бүрэн
идэгдэж зураглал бага зэрэг хасагдана — эдгээр нь туйлын харьцаа тул
хамрахыг зориогүй.

## ⚠ Бичвэрийн хөвөө ХУВИАР

`lg:px-[12%]` — тогтмол пикселээр БИШ. Зураглалын зүүн ирмэг нь зотоны
өргөний **8.2%**-д сууна; цонхны харьцаа зотоныхоос (1.58) өргөн байдаг
тул зураг хэвтээгээр бүтэн багтаж, тэр 8.2% нь дэлгэцийн 8.2% болж
хөрвөнө. Тогтмол пикселээр өгвөл нарийн цонхон дээр бичвэр хүрээн дээр
гарна.

## ⚠ Бичвэр зураг дээр ШУУД сууна — контрастыг хэмж

Ширээний компьютерт хөшиг БАЙХГҮЙ (хэрэглэгчийн шийдвэр). Бичвэр зургийн
зүүн гуравны нэгд, бүдгэрсэн бараан уулс дээр сууна.

Одоогийн зургийн хэмжилт:

| Хаана | Дундаж контраст | 4.5:1-ээс доош унах цэг |
|---|---|---|
| Ширээний компьютер (зүүн гуравны нэг) | 16:1 | **0.00%** |
| Гар утас (зураглалын дунд), хөшиггүй | 12:1 | 17.4% |
| Гар утас, 45% хөшигтэй | — | 2.8% |

Тиймээс **гар утсанд хөшиг үлдсэн** (`bg-paper/45 lg:bg-transparent`):
тэнд `bg-cover` нь өндрөөр масштаблаж хэвтээгээр ердөө 29% нь харагдана
— яг зураглалын гэрэлтэй дунд хэсэг.

⚠ **Зураг солих бүрд хэмжинэ.** Цайвар зүүн талтай зураг тавибал бичвэр
уншигдахаа болино. Хэмжих арга:

```bash
node -e "
const sharp=require('sharp');
(async()=>{
  const f='public/auth/background.webp';
  const m=await sharp(f).metadata();
  const L=Math.round(m.width*0.12), W=Math.round(m.width*0.20);
  const T=Math.round(m.height*0.438), H=Math.round(m.height*0.124);
  const {data}=await sharp(f).extract({left:L,top:T,width:W,height:H})
    .raw().toBuffer({resolveWithObject:true});
  let bad=0,n=0;
  for(let i=0;i<data.length;i+=3){
    const lum=(0.2126*data[i]+0.7152*data[i+1]+0.0722*data[i+2])/255;
    const Lr=lum<=0.03928?lum/12.92:Math.pow((lum+0.055)/1.055,2.4);
    if(1.05/(Lr+0.05)<4.5)bad++; n++;
  }
  console.log('унах цэг: '+(bad/n*100).toFixed(2)+'%');
})();
"
```

## ⚠ Зургийн БҮТЭЦ нь байрлуулалтыг тодорхойлно

Зураглал, зангилаанууд нь өргөнийхөө **37%-иас баруун тийш**, зүүн
гуравны нэг нь бүдгэрсэн уулархаг дэвсгэр. Тиймээс нэвтрэх бичвэр
**ЗҮҮН** талд сууж, хөшиг нь тэр тийш өтгөрдөг.

Агуулга нь нөгөө тал руугаа байрласан зураг тавих бол
[`sign-in.tsx`](../../src/components/auth/sign-in.tsx) дотор **ХОЁРЫГ
ЗЭРЭГ** эргүүлнэ: бичвэрийн блокт `justify-end` нэмэх, хөшгийн
`bg-gradient-to-r` → `-to-l`. Ганцыг нь өөрчилвөл хөшиг яг гол агуулгыг
дарна — нэг удаа ингэж эргүүлээд буцаасан.
